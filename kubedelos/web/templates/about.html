How fresh the data is

Trivy publishes a new vulnerability DB a few times a day. kubedelos updates it at the start of each scan, so findings are as fresh as the newest scan.

The project

  • kubedelos reads the cluster and never changes the cluster: it lists namespaces and pods, and never reads Secrets.
  • Registry logins stay in your Docker config. kubedelos never stores credentials or writes them to a log.
  • This UI listens on loopback only, and its startup URL carries a token that is new on every start.
  • Images are scanned with a pinned Trivy, checked against its SHA-256, for vulnerabilities only.
