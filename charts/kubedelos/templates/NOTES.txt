{{- $name := include "kubedelos.fullname" . -}}
{{- $exposed := or .Values.ingress.enabled .Values.httpRoute.enabled -}}
{{- $trust := .Values.auth.trustProxyHeaders -}}
kubedelos serve is installed as {{ $name }} in the {{ .Release.Namespace }} namespace, for cluster {{ .Values.clusterName | quote }}.
Its UI is the Service {{ $name }}.{{ .Release.Namespace }}.svc, port 80.
To reach it from your machine, run kubectl port-forward svc/{{ $name }} 8080:80 -n {{ .Release.Namespace }}
and open http://localhost:8080. The NetworkPolicy does not block port-forward.
{{- if .Values.secureCookies }}
Safari drops Secure cookies on http://localhost, so forms there fail as expired; use another browser, or set
secureCookies=false if you only reach the UI over plain HTTP.
{{- end }}
{{- if and .Values.networkPolicy.enabled (empty .Values.networkPolicy.ingressFrom) }}

The NetworkPolicy admits no traffic yet. Name your proxy, gateway or Ingress controller in networkPolicy.ingressFrom.
{{- end }}
{{- if and $exposed (not $trust) }}

WARNING: the UI is exposed and has no sign-in. Anyone who can reach the host can read the whole vulnerability inventory.
{{- if not .Values.readOnly }} They can also start scans and accept risks, unless your proxy guards it.{{ end }}
{{- end }}
{{- if and (not .Values.readOnly) (not $trust) }}

WARNING: writes are open and every user is anonymous. Accepting a risk hides its findings, and anyone
can do it under any name. Set readOnly: true, or put a sign-in proxy in front and set auth.trustProxyHeaders.
{{- end }}
{{- if $trust }}

kubedelos trusts the {{ .Values.auth.identityHeader }} header, and the NetworkPolicy limits who can send it. These paths skip
your proxy: kubectl port-forward to the pod or Service, a CNI that does not enforce NetworkPolicy, and on many CNIs
traffic from hostNetwork pods or the node itself. NetworkPolicies are additive, so any other policy that selects this
pod and allows more ingress defeats this one. Limit who may port-forward in this namespace, check that your CNI
enforces NetworkPolicy, and check the other policies in this namespace.
{{- end }}
{{- if .Values.registries.podPullSecrets }}

Pod pull secrets are on: kubedelos can read (get) any Secret in {{ join ", " .Values.registries.podPullSecretNamespaces }}, not only image pull secrets, through a Role per namespace.
Keep that list to namespaces whose Secrets you accept sharing with this deployment.
{{- end }}
{{- if and .Values.threatFeeds.enabled .Values.networkPolicy.enabled .Values.networkPolicy.egress }}

Threat feeds are on and networkPolicy.egress restricts egress: allow HTTPS (443) to www.cisa.gov and
epss.empiricalsecurity.com, or the downloads time out before each scan and the risk score counts no known exploitation.
{{- end }}
